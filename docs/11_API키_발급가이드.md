> 각 항목의 `*_BASE`(엔드포인트) 기본값은 `config.py`에 하드코딩되어 있으므로 아래 표의 값을 `.env`에 다시 넣을 필요는 없다. 값을 바꿔야 할 때만 `LAW_BASE=` 등으로 override.

## 1. LAW_OC — 국가법령정보 공동활용 OpenAPI

**무엇:** 법령·자치법규(조례/규칙)·법령해석례 등을 조회하는 법제처 OpenAPI. 본 프로젝트는 **자치법규 목록/본문 조회**(`target=ordin`)에 사용한다. 조인 스파인(조례 → 지자체) 및 조문 원문 캐시의 원천.

| 항목 | 내용 |
|---|---|
| 발급 URL | 활용가이드 <https://open.law.go.kr/LSO/openApi/guideList.do> · **OPEN API 신청** <https://open.law.go.kr/LSO/openApi/cuAskList.do> [실측 메뉴 링크] |
| 로그인·인증 | open.law.go.kr **회원가입(이메일 인증)** 후 로그인 |
| 발급 방식 | **승인대기**. 활용신청 제출 → 검토 → 가입 이메일로 승인 통보. 영업일 **1~2일** 소요 (추정, 집계 가이드 근거) |
| 무료·한도 | 무료. 문서상 일일 호출 한도 명시 없음 (확인 필요) |
| 도메인·IP | **운영키는 활용 IP/URL 등록 필요** [실측 `.env.example`]. 신청서에 활용 서비스 정보 기재 |
| .env 변수 | `LAW_OC` = **가입 이메일의 ID 부분(@ 앞)**. 예: `g4c@korea.kr` → `LAW_OC=g4c` [실측 `.env.example` 주석] |
| 엔드포인트 | `https://www.law.go.kr/DRF` (config `law_base`). 요청 필수 파라미터 `OC`(인증값), `target`(예 `ordin`), `type`(HTML/XML/JSON) [실측 가이드] |

**단계별 체크리스트**
1. [ ] <https://open.law.go.kr> 접속 → 우측 상단 **회원가입** → 이메일 인증 완료
2. [ ] 로그인 → 상단 메뉴 **OPEN API → OPEN API 신청**(`/LSO/openApi/cuAskList.do`)
3. [ ] 활용 목적·활용 서비스(운영 IP/URL 포함) 작성 후 제출
4. [ ] 승인 통보(가입 이메일) 수신 → 마이페이지 **OPEN API 신청현황**에서 상태 확인
5. [ ] `.env`에 `LAW_OC=<가입이메일 @앞부분>` 입력

> **주의 1 — OC 정의:** 가이드 페이지 파라미터 표에는 "OC: 신청한 API인증값"으로만 적혀 있고 예시는 `OC=test`다 [실측]. 실제 운영 관행상 값은 **가입 이메일의 ID(@ 앞부분)**이며, 사이트에 따라 이메일 전체를 넣는 경우도 있으니 승인 통보 문구를 반드시 확인할 것.
> **주의 2 — 개발용 test 키:** 현재 `LAW_OC=test`가 개발 검증용으로 동작한다 [실측 `.env.example`]. 실운영 수집 전 팀 계정으로 자체 발급 권장.

## 3. VWORLD_KEY + VWORLD_DOMAIN — 브이월드 공간정보 오픈플랫폼

**무엇:** 국토교통부 V-World 공간정보 데이터 API. 행정경계 등 지오데이터 보강용. 본 프로젝트 경계는 이미 southkorea-maps 2018 로컬본을 1차로 쓰므로(08 문서(팀 내부 문서 — 공개본에 포함하지 않는다)), V-World는 **보완/검증용**이다.

| 항목 | 내용 |
|---|---|
| 발급 URL | <https://www.vworld.kr> → **오픈API → 인증키 → 인증키 발급** |
| 로그인·인증 | vworld.kr **회원가입(이메일 인증)** 후 로그인 |
| 발급 방식 | 인증키 신청(활용 API 종류 + 서비스 URL 입력) → 인증키 관리에서 상태가 **'승인'**으로 전환. 대체로 즉시~단시간이나 정확 소요 (확인 필요) |
| 무료·한도 | 무료. **API별 상이** — 배경지도/정적지도는 요청 제한 사실상 없음(서버 부하에 따라 변동), **지오코더 등 일부 API는 일별 요청 제한**이 있어 초과 시 홈페이지에서 초과신청 [실측 검색] |
| 도메인·IP | **서비스 URL(도메인) 등록 필수.** 서버 호출 시 요청의 도메인이 **등록 도메인과 일치**해야 동작 [실측 `.env.example` + 검색]. 등록 URL은 블로그/카페 등 형식 자유 |
| .env 변수 | `VWORLD_KEY` + `VWORLD_DOMAIN`(등록 도메인, 개발 시 `http://localhost` 사용 가능) [실측 `.env.example`] |
| 엔드포인트 | `https://api.vworld.kr/req/data` (config `vworld_base`) |

**단계별 체크리스트**
1. [ ] <https://www.vworld.kr> 접속 → **회원가입** → 이메일 인증 → 로그인
2. [ ] **오픈API → 인증키 → 인증키 발급** 이동
3. [ ] 활용 API 종류 선택 + **서비스 URL(도메인) 입력**(개발은 `http://localhost`) → 발급 신청
4. [ ] 인증키 관리에서 상태가 **'승인'**인지 확인(필요 시 이메일 인증 링크 클릭)
5. [ ] `.env`에 `VWORLD_KEY=<발급키>`, `VWORLD_DOMAIN=<등록한 도메인>` 입력
6. [ ] 검증: 서버에서 호출할 때 `domain` 파라미터를 `VWORLD_DOMAIN`과 동일하게 보내야 인증 통과

> **주의:** 운영 배포 시 등록 도메인을 실제 서비스 도메인으로 갱신하지 않으면 서버 호출이 거부된다. 개발/운영 도메인이 다르면 인증키를 용도별로 나눠 발급.

## 4. LOFIN_KEY — 지방재정365 재정데이터 OpenAPI

**무엇:** 지방재정 통합공개(세부사업별 세출현황 등) OpenAPI. 08 문서(팀 내부 문서 — 공개본에 포함하지 않는다)의 세출예산 축 원천. 엔드포인트가 **lofin365.go.kr 자체 데이터허브(`/lf/hub`)**이며, config 기본 서비스는 `QWGJK`(세부사업별 세출현황) [실측 `.env.example`].

| 항목 | 내용 |
|---|---|
| 발급 URL | <https://www.lofin365.go.kr> → **재정데이터개방** 메뉴(재정 데이터를 다양한 포맷으로 제공) [실측 메인 메뉴] |
| 로그인·인증 | lofin365.go.kr **회원가입** 후 로그인 |
| 발급 방식 | lofin365 자체 발급 절차의 자동/승인 여부는 (확인 필요) — 페이지가 로그인 뒤. **대안 경로**: 동일 계열 데이터셋이 공공데이터포털(data.go.kr)에도 다수 존재(예: 예산서 15138708, 세입세출현황 15058182)하며 그 경우 **개발단계 자동승인(즉시)**·운영단계 데이터셋별(재정공시는 심의승인) [실측 data.go.kr] |
| 무료·한도 | 무료. **인증키 신청형·요청제한 없음** [실측 `.env.example`] |
| 도메인·IP | 불필요 (추정) |
| .env 변수 | `LOFIN_KEY`. **요청 파라미터명(`Key` vs `serviceKey`)은 실키 발급 후 확정 필요** [실측 `.env.example` 주석] |
| 엔드포인트 | `https://www.lofin365.go.kr/lf/hub` (config `lofin_base`), 기본 서비스 `QWGJK` |

**단계별 체크리스트**
1. [ ] <https://www.lofin365.go.kr> 접속 → **회원가입** → 로그인
2. [ ] **재정데이터개방** 메뉴에서 OpenAPI/인증키 신청 항목 확인 → 활용 데이터(세출현황 등) 선택 후 인증키 신청

## 5. STANREGIN_KEY (선택) — 행정표준코드 법정동코드

**무엇:** 행정안전부 행정표준코드관리시스템의 **법정동코드 목록조회** OpenAPI. **조인 스파인인 법정동코드 10자리**([05 문서](./05_시스템_설계.md)) 확보/갱신용. 이미 로컬 참조본으로 대체 가능해 **선택 항목**이나, 정본 갱신 시 유용.

| 항목 | 내용 |
|---|---|
| 발급 URL | 공공데이터포털 상세 <https://www.data.go.kr/data/15077871/openapi.do> → **활용신청** |
| 로그인·인증 | data.go.kr **회원가입(휴대폰 본인인증 또는 i-PIN)** 후 로그인. **신청은 PC에서만 지원** (추정, 집계 가이드) |

| 무료·한도 | 무료. **개발계정 일 10,000건**, 운영계정은 활용사례 등록 시 증가 [실측] |
| 도메인·IP | 불필요 |
| .env 변수 | `STANREGIN_KEY`. 요청 파라미터명 **`ServiceKey`** [실측] |
| 엔드포인트 | `https://apis.data.go.kr/1741000/StanReginCd` (config `stanregin_base`), 오퍼레이션 `getStanReginCdList`. 필수값 `ServiceKey`, `pageNo`, `numOfRows`, `type`(xml/json) [실측] |

**단계별 체크리스트**
1. [ ] <https://www.data.go.kr> 회원가입(본인인증) → 로그인
2. [ ] `행정표준코드 법정동코드` 검색 또는 직접 <https://www.data.go.kr/data/15077871/openapi.do> 접속
3. [ ] **활용신청** 클릭 → 활용 목적 작성 → 라이선스 동의 → 신청(자동승인, 즉시)

## 6. 발급 완료 후 공통 마무리

1. [ ] `system/.env.example`를 `system/.env`로 복사하고 위 5개 값(선택 포함)을 채운다.
2. [ ] `.env`는 **커밋 금지**(git 추적 제외). CI는 저장소 secrets/vars로 주입.
3. [ ] 연결 점검: 각 수집기 진입부의 `Config.require(...)`가 통과하는지 드라이런.
   - 예상 매핑: `law_oc`(자치법규 수집), `assembly_key`(국회), `vworld_key`+`vworld_domain`(경계), `lofin_key`(세출), `stanregin_key`(법정동코드).
4. [ ] 실패 시 메시지 "필수 설정 누락: … — .env 또는 환경변수를 확인하라"가 뜨면 해당 변수 재확인 [실측 `config.py`].

### 확인 필요(발급 시 실측으로 확정할 것)
- `LAW_OC`: OC가 이메일 ID(@앞) 형태인지 승인 통보 문구로 최종 확인. 일일 한도 유무.
- `ASSEMBLY_KEY`: 일일 호출 상한 수치.
- `VWORLD_KEY`: 데이터 API의 일별 요청 제한 수치, 승인 소요 시간.
- `LOFIN_KEY`: lofin365 자체 발급의 자동/승인 여부, 파라미터명(`Key` vs `serviceKey`), `QWGJK` 서비스명 재검증.

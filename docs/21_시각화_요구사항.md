## 0. 이 사이트가 존재하는 이유 (한 문장)

> **지자체 실무자가 "우리 시에도 이 조례 만들어야 하나?"를 물었을 때,
> 유사 지자체 근거·선례 원문·폐지 사례·예산 집행까지 한 화면에서 답하는 것.**

팀 최초 논의(카톡)의 문장을 그대로 옮기면:

> "실무자가 무슨 조례 만들라는데 우리랑 비슷한 지역이 이미 만든 조례가 있나 가져와서 보는 용도.
>  이걸 지금 구글링이나 전화로 하고 있고… 우리가 정책 비슷한 지역이랑 유사 조례 갖다주면
>  돈이랑 시간 아끼는 도구 된다."

**따라서 판정 기준은 하나다**: 실무자가 이 화면을 보고 **구글링·전화를 대체할 수 있는가.**
예쁜 대시보드가 아니라 **의사결정에 쓸 수 있는 근거**가 나와야 한다.

## 1. 절대 요구사항 (P0) — 이게 없으면 출품작이 아니다

### P0-1. 격차 분석 — 킬러 기능

**무엇**: 특정 지자체를 선택하면 "유사 지자체 N곳에는 있는데 우리에게 없는 조례" 목록.

**왜 P0**: 이게 프로젝트의 존재 이유다. 나머지 화면이 다 빠져도 이건 있어야 한다.
심사 배점 **독창성 15 · 효과성 15 · 활용성 15** 가 여기 걸린다.

**수용 기준**
- [x] 지자체 선택 → 추천 목록이 **보유 지자체 수 내림차순**으로 나온다
- [x] 각 항목에 **선례 지자체명 + 제정일 + 원문 링크**가 붙는다 (링크는 law.go.kr 실제 조문으로 열려야 함)
- [x] **폐지 경고**: 유사 지자체 중 그 조례를 폐지한 곳이 있으면 `⚠ N곳 보유 / M곳 폐지` 배지와
      폐지 지자체·폐지일을 표시한다
- [x] "왜 이 지자체와 비교하나"를 클릭 한 번으로 볼 수 있다(인구·재정자립도·예산 비교표)
      → **추가**: `#/analytics?tab=peers` 에서 선정 방식 3종의 Top-10 이 얼마나 갈리는지까지 공시한다
      (227곳, 행안부정렬 vs 구 방식 겹침 평균 Jaccard **0.172**)
- [x] 폐지된 조례가 **선례로 추천되지 않는다** (`status='repealed'` 필터)

**데이터**: `api/gap.json` · `api/peers.json` (실데이터는 MCP `gap_analysis`/`similar_regions`)

**실제 출력 예시** (종로구, 실측):
```
발달장애인 권리보장 및 지원   25곳 보유    중구(2016-12-28) · 성동구(2017-05-18)
장기요양요원 처우개선        22곳 보유 / ⚠ 2곳 폐지   동대문구(2024-05-09 폐지)
```

### P0-2. 표기 규율 — 신뢰성 장치

**왜 P0**: 심사 **정확성 15점**이 여기 걸린다. 다른 출품작이 "정확합니다"라고 말할 때
우리는 **"어디까지 검증했고 어디부터는 추정인지"** 를 화면에 공시한다. 이게 차별점이다.

**수용 기준**
- [x] **데이터 기준일(`as_of_date`)이 모든 화면에 상시 노출**된다 — 14/14 화면 DOM 실측
- [x] `stale=true` 면 눈에 띄는 경고를 띄운다 (`staleBanner`, `manifest.watermarks` 498행 기반)
- [x] **조례↔예산 연결에는 반드시 "추정 연결" 배지 + confidence 등급**이 붙는다
      - `verified=1` 인 건만 "확인됨" 표기 가능 (전체 183,145건 중 **421건뿐**)
      - 등급 예: 높음(≥0.8) · 중간(0.65~0.8) · 낮음(<0.65)
      - 근거: 표본 584건 검증 결과 **전체 정밀도 64.9%, conf≥0.8 구간 93.2%** ([17 문서](./17_링크_표본검증_보고서.md))
- [~] 가상데이터(`_mock:true`)로 동작 중이면 **상단에 경고 배너**가 상시 표시된다
      → 발표용 스크린샷에서 배너가 화면을 가려 커밋 `91e813d` 로 제거했다. 대신 가상 모드에서는
        실데이터 전용 화면이 «현재 데이터 소스에 없습니다» 패널로 강등돼 구분이 된다. **미충족 상태다.**
- [x] 폐지 조례는 어디서 보이든 `폐지(YYYY-MM-DD)` 표기가 붙는다

> **이 규율을 어기면 시스템이 거짓말을 한다.** 예산 연결 9.5만 건 중 검증된 건 421건뿐인데
> 이를 사실처럼 보여주면, 실무자가 잘못된 근거로 예산을 편성할 수 있다.

### P0-3. 지도 — 공간정보 경진대회의 최소 요건

**왜 P0**: **공간정보** 활용 경진대회다. 지도가 없으면 부문 정합성 자체가 흔들린다.

**수용 기준**
- [x] 전국 시군구 경계가 렌더된다 (250 feature) — `#/map` `#/spatial` 둘 다 path 250개 실측
- [x] 지표별 코로플레스 전환: **조례 수 · 카테고리별 보유 · 예산 집행률** 최소 3종 (지도 4종 + 공간분석 7종)
- [x] 지역 클릭 → 상세 패널(P1-1)로 연결된다
- [x] **통계청코드 → 법정동 `sig_cd` 변환이 적용**돼 있다
- [x] 일반구를 둔 시(수원·성남 등)는 **상위 단위로 롤업**해 표시한다

**함정**: 경계 파일 `properties.code` 는 통계청코드(종로구 `11010`)라 우리 `sig_cd`(`11110`)와 다르다.
`reference/kostat_to_bjd.json` 크로스워크 필수. `viz/tools/build_geo.py` 에 처리돼 있다.

## 2. 핵심 요구사항 (P1) — 공모전 경쟁력

### P1-1. 지역 상세
지역 하나의 프로필. 조례 수(조례/규칙 구분) · 카테고리 분포 · 예산 규모 · 최근 변경.
- [x] `regions/{sig_cd}.json` 하나만 읽어 렌더된다(추가 요청 없이)
- [x] 교육청(level=4)·폐지 지자체는 "현행 지자체 아님" 안내를 띄운다

### P1-2. 유사 지자체
행안부 유사자치단체 기준에 정렬된 Top-N.
- [x] 유사도 점수와 **왜 유사한지**(인구·재정자립도·예산·면적 비교)를 함께 보여준다
- [x] 가중치 출처를 표기한다(`mois_public` = 행안부 공개기준, `ours` = 우리 설정)
- [x] **일반구(level=3)** 선택 시 "조례 제정권이 없어 비교 대상이 아님 → 모 자치단체로 안내"

### P1-3. 법령 위계 그래프
조례 → 상위법 위임(`DELEGATED_FROM`), 인용(`CITES`) 관계 시각화.
- [x] 조례 하나를 중심으로 한 **서브그래프**(2~3홉)를 그린다 — `api/graph/` shard 422개
- [x] 전체 그래프(25만 노드)를 브라우저에 통째로 던지지 않는다 — **자동 로드 차단 가드 필수**
- [x] 노드 클릭 → 해당 조례/법령 상세로 이동
- [x] **추가**: 상위법 조문 열람(`articles` 86,745행 중 200법령), 이름해소로 CITES 0.3% → 74.5%

### P1-4. 조례 실효성 (조례 ↔ 예산)
"조례는 있는데 예산이 안 잡힌 지자체" 탐지.
- [x] 편성액·지출액·집행률을 함께 보여준다
- [x] **P0-2 표기 규율 적용 필수** (추정 배지 + confidence)
- [x] 집행률 100% 초과 건이 있으면 원천 데이터 그대로임을 주석으로 밝힌다

### P1-5. 정책 생애주기 / 확산
제정 → 개정 → 폐지 타임라인.
- [x] 연도별 제정 추이와 **폐지 추이를 함께** 보여준다 — `#/lifecycle` 신설, 폐지 40,406건 전량
- [x] ⚠ **주의**: `enacted_on` 은 현행 판본 공포일이라 그대로 쓰면 확산이 아니라 **개정 활동**을 그린다.
      `rr_cls_cd='제정'` 필터를 걸거나, 필터 없이 그릴 때는 **"개정 포함 활동량"이라고 명시**할 것
      → `rr_cls_cd` 누적 막대로 제정 49,971 / 일부개정 100,109 / 전부개정 7,735 / 타법개정 1,637 /
        폐지 40,406 을 분해해 표시한다. EHA·확산 화면도 `mode=enactment` 커버리지를 배지로 병기한다.
- [x] 「저탄소 녹색성장 기본 조례」 186곳 일괄 폐지 같은 **상위법 개정에 따른 물갈이**를 보여주면 강력
      → 일괄폐지 코호트 11건 카드(2015-01-01 사회단체보조금 80곳 → 지방재정법 등),
        최다 폐지 정책 TOP100(저탄소녹색성장기본조례 179곳 실측)

### P1-6. 국회 표결
법안별 찬반·정당 비율.
- [x] 정당별 찬성/반대/기권/**불참**을 스택 차트로 — 의안 149건(초기 15건)
- [x] `POLY_NM` 은 **표결 당시 정당**임을 표기(당적 변경 이력 반영)

### P1-7. 검색
조문 단위 검색.
- [x] 결과 카드에 조례명 · 지자체 · 조문번호 · 본문 발췌 · 원문 링크 — 사전계산 40질의(C01~C14 전 분류)
- [x] ⚠ 그래프 확장을 **검색 랭킹에 섞지 말 것** — 무익함이 실증됐다([15 문서](./15_법률RAG_연구와_개선안.md))
      대신 결과 하단 **"이 조례와 연결된 것들"** 패널로 분리 배치

### P1-8. 대시보드
전국 요약 진입점. 총량 카드 · 카테고리 분포 · 최근 변경 피드.

## 5. 심사 배점과의 연결

| 배점 | 화면 | 어떻게 방어하나 |

## 0. 한 문단 요약

DB 33개 테이블 중 **행이 있는 31개 가운데 30개가 화면에 도달**한다.
나머지 2개(`ordinance_appendix`·`code_crosswalk`)는 0행이라 애초에 반영할 것이 없고,
행이 있는데도 화면에 없는 것은 `embeddings`(1,087행, 구 조문 임베딩 캐시) 하나다.
분석 엔진 쪽에서는 이번 작업으로 `analytics.eha`·`rag.community`·`analytics.peers.compare_peer_methods`·
`analytics.spatial.moran`·`neural.embeddings.top_k_matrix` 가 전부 화면에 붙었고,
남은 미노출은 `rag.community.global_search` 와 `neural.embeddings.most_similar`(메모리판) 둘이다.
정적 번들은 이번 전량화로 **75.82 MiB / 4,972 파일**, 최대 파일 443.0 KB다
(사전압축 전 405.6 MB → gzip 사전압축 후 75.82 MB, 5.2배). 250 MB 배포 예산과 GitHub 100 MB
파일 한계를 모두 지키면서 **데이터는 한 건도 버리지 않았다** — 자세한 것은 §1.5 와 §1.6 을 보라.

### 1.6 250 MB 예산을 맞춘 방법 — 데이터를 버리지 않고 사전압축했다

전량 생성을 끝낸 시점의 `api/` 는 **405.6 MB / 4,972 파일**로 배포 예산 250 MB 를 크게 넘었다.
검토한 감축안과 그 대가는 아래와 같다.

| 감축안 | 절감 | 잃는 것 |
|---|---:|---|
| 조문 제목 번들 삭제 | -66.4 MB | 배포본에서 조문 목록 자체가 사라진다 |
| 신경망 Top-10 → Top-3 | -49.0 MB | 유사도 4~10위 손실 |
| 그래프 조례 shard 1,000 → 300 | -15.0 MB | 조문 단위 근거·인용 표본 축소 |
| **gzip 사전압축(채택)** | **-329.8 MB** | **없음** |

JSON 은 4~10배로 압축된다(실측 평균 5.2배). 그래서 데이터를 깎는 대신
`system/tools_compress_api.py` 로 `api/<디렉터리>/**/*.json` 을 전부 `.json.gz` 로 구웠다.

- **결과**: 405.6 MB → **75.82 MB** (5.2배). 예산 250 MB 대비 3.3배 여유.
- 남은 여유로 신경망을 Top-5(53.1 MB) 대신 **Top-10 으로 다시 구웠다** —
  `neural_similarity` 저장본 1,877,420행 **전량**이 배포본에 들어간다.
- 최상위 카탈로그 `api/*.json` 19개는 압축하지 않았다(부팅 경로를 단순하게 두려고).
- 읽는 쪽은 `viz/public/js/api.js` 의 `getJSONFromBase()` 한 곳이다. 서버가
  `Content-Encoding: gzip` 을 붙이면 브라우저가 알아서 풀고, 안 붙이면
  (`python -m http.server`·`serve_full.py`·Vercel 정적) gzip 매직바이트 `0x1f8b` 를 보고
  `DecompressionStream` 으로 직접 푼다. **서버 설정에 의존하지 않는다.**
  `.json.gz` 가 404 면 비압축 `.json` 으로 폴백하므로 압축 전 번들도 그대로 열린다.
- 가상데이터(`viz/public/data`)에는 `api/` 하위 디렉터리가 없으므로 `.gz` 요청을 아예 만들지 않는다
  (`?src=mock` 7개 화면에서 `.gz` 요청 **0건** 실측).
- 되돌리려면 `python system/tools_compress_api.py --decompress`.

> **브라우저 요건**: `DecompressionStream` 은 Chrome 80+ / Firefox 113+ / Safari 16.4+ 에서 쓸 수 있다.
> 그보다 낮은 브라우저는 안내 문구를 띄우고 멈춘다(조용히 빈 화면이 되지 않는다).

## 5. 이번 작업에서 실제로 고친 것

1. **표결 15건 → 149건, 검색 5질의 → 40질의가 화면에서 선택 불가였다.**
   `make_extend_fixtures.py` 가 shard 를 구웠지만 목록이 `api/votes_index.json`·`api/search_index.json`

   `config.EXTRA_CATALOGS` 를 두고 두 색인을 key 로 병합하도록 고쳤다. 실측: 표결 선택기 149항목,
   검색 선택기 40항목.
2. **검색 화면이 shard 를 아예 쓰지 않았다.** `views/search.js` 가 단일 `api/search.json` 만 읽어
   질의 1건만 보여줬다. 카탈로그 선택기를 붙여 40질의를 고를 수 있게 했다(C01~C14 전 분류 커버).
3. **EHA·커뮤니티 산출물이 어느 화면에도 붙어 있지 않았다.** `api/eha/`·`api/community/` 가
   생성만 되고 소비되지 않았다 — `views/analytics.js`(신규)로 붙였다.
4. **`compare_peer_methods` 가 `sqlite3.Row` 없이 호출되면 조용히 반쪽이 된다.**
   raw `sqlite3.connect` 로 넘기면 `legacy` 경로가 `ValueError: dictionary update sequence element #0
   has length 5` 로 죽고 `legacy_error` 만 남아, 3방식 비교가 2방식(그것도 서로 동일)으로 쪼그라든다.
   생성기는 `policymap.db.connect()`(row_factory 설정됨)를 쓰도록 하고 주석에 이유를 남겼다.
5. **구 방식(legacy)이 돌려주는 지자체 이름에 시도 접두어가 없어 동명 지자체가 구분되지 않았다**

## 6. 남은 한계 — 정직하게

### 6-1. 데이터가 없어서 못 하는 것

- **held-out AUC 산출 불가.** GraphSAGE 학습 시점의 `split_edges` 분할이 DB(`schema_meta`·`watermarks`)에
  저장돼 있지 않아 복원할 수 없다. 지금 다시 계산하면 학습 엣지가 섞여 과대추정된다.
  화면에는 `held_out_auc = null` 과 사유 문자열을 그대로 띄운다. 표시된 AUC(0.83~0.90)는
  **in-sample 지자체 분리 AUC** 이며 배너로 명시한다.
- **폐지 조례 40,406건은 임베딩에 없다.** 학습 그래프가 현행 조례만 담았다(pool: active 154,310 / repealed 0).
  신경망 화면으로 폐지 조례 생애주기를 만들 수 없어 `method.repealed_note` 에 수치와 함께 적었다.
  대신 생애주기 화면이 `ordinance_work` 기반으로 폐지 40,406건을 전량 다룬다.
- **2026년 신설 지자체(제물포구·영종구·서해구·검단구·곡성군 등)는 재정 지표가 없다.**

### 6-2. 표본이라서 전수가 아닌 것

### 6-3. 방법론상 조심해야 하는 것

- **이웃효과는 지지되지 않는다.** 3템플릿 모두 `neighbor_effect_supported = false` 다.
  안전보안관은 유의하지만 **부호가 음(-0.4221, p=0.0236)** 으로 수평확산 가설과 반대다.
  민감도(정의·링크 교체) 4모형에서도 결론이 뒤집히지 않는다. 화면은 이 결론을 먼저 띄운다.
- **유사 지자체는 방법 선택에 크게 좌우된다.** 행안부 정렬 방식과 구 방식의 Top-10 겹침은
  **평균 Jaccard 0.172**(227곳 중 legacy 산출 성공 196곳)에 불과하다. 즉 "무엇이 격차인가"는
  비교 대상 선정 방식에 달려 있다. 방법비교 탭이 이 사실을 공시한다.
- **조례↔예산 연결 183,145건 중 `verified=1` 은 421건뿐이다.** 나머지는 확률적 추정이며
  추정 배지 + confidence 등급이 붙는다(표본 584건 검증: 전체 정밀도 64.9%, conf≥0.8 구간 93.2%).
- **공간통계는 인과가 아니다.** 채택연도 Moran's I 는 전역에서 유의(+0.21, p=.002)하지만
  시도 고정효과를 뺀 잔차에서도 +0.19 로 거의 줄지 않고, 국지 LISA 는 FDR 통과 0곳이다.
- **커뮤니티 size 와 전국 투영을 섞어 읽으면 안 된다.** 유사도 그래프는 본문 확보 조례만 덮는다.
- **이름해소는 추론이다.** CITES 605,424건(74.5%)·위임 +7,881건은 법령명 정규화 대조로 붙였고,
  노드·엣지에 `resolved_by='name-match'`·`inferred` 를 병기한다. 해소 실패분은
  `resolved=false` placeholder 로 남겨 "수집 안 된 상위법"임을 드러낸다.
